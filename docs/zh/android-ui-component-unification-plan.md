# ClawSeed Android 基础控件统一风格开发计划

日期：2026-11-05

状态：公共组件和页面迁移已实施，设备验收待完成

技术栈：Kotlin / Jetpack Compose / Material 3

## 1. 目标与范围

参考 `work_dirs/dsh-Go/app` 的主题与组件组织方法，统一 ClawSeed 的按钮、选项、输入框、设置行、卡片和弹层。通过设计令牌、统一主题入口和公共组件，让同类控件在不同页面具有一致的尺寸、颜色、状态反馈和无障碍行为。

本计划独立于 [Android UI 局部与风格优化方案](android-ui-visual-design-plan.md)，聚焦基础控件治理。旧方案中的首页比例、输入栏和真机验证经验继续保留；本文提出的新尺寸与材质分层是待实施目标，不表示代码已经完成迁移。已有首页 4dp 阴影等视觉约定不因基础组件默认值调整而自动改变，应在对应页面迁移时单独复核。

范围仅限 Android 应用的 UI 层。保持导航、ViewModel、配置保存、会话切换、附件、定时任务、Persona 和用户资料的业务行为；不修改 Rust、SDK 协议或 Gateway API。

## 2. 当前实现与缺口

以下路径均相对于仓库根目录；UI Kotlin 目录为 `clients/android/app/src/main/kotlin/dev/clawseed/demo/`。

| 位置 | 当前实现 | 计划 |
|---|---|---|
| `MainActivity.kt` | 根据明暗/OLED 设置注入 `MaterialTheme(colorScheme)` | 改用统一 `ClawSeedTheme`，同时提供字体和形状 |
| `ui/theme/AppColors.kt` | 浅色、深色、OLED 配色及成功语义色 | 保留现有配色基础，补齐组件需要的语义角色 |
| `ui/theme/DesignTokens.kt` | 基础颜色和 10/16/24/28dp 圆角 | 收敛颜色来源，补充间距、尺寸和形状规范 |
| `ui/components/GlassSurface.kt` | Surface/Elevated 两层填充、描边和可选阴影，无背景模糊 | 扩展材质角色并兼容已有调用 |
| `ui/components/VisionModeSelector.kt` | 使用原生 `FilterChip` 组合选项 | 接入统一选项组件 |
| `ui/settings/SettingsScreen.kt` | 多处直接组合 Card、输入框、Chip、Switch | 作为首个完整迁移页面 |
| `ui/chat/components/ChatBottomBar.kt` | GlassSurface + BasicTextField + 自定义圆键 | 保留输入机制，统一外壳和按钮样式 |
| `app/src/test/kotlin/dev/clawseed/demo/ui/theme/AppColorsTest.kt`（相对 Android 目录） | 已覆盖配色对比度、OLED 和 Persona 颜色 | 扩展到实际组件表面与状态 |

主要缺口是重复的局部样式和缺少统一组件入口。只调整 `MaterialTheme` 的颜色不能自动统一所有控件的边框、内边距、选中态和布局，需要公共 Composable 显式提供这些默认值。

## 3. 视觉原则

- 保留 ClawSeed 的低饱和蓝灰强调色；主操作、筛选状态、成功和错误具有不同语义。
- 层次主要通过填充、留白与细边框表达，普通卡片默认无阴影。
- 普通表单使用中等圆角；筛选、分段选项和聊天输入栏使用胶囊形状。
- 明暗主题共用组件结构，OLED 模式保留现有纯黑底与可辨认的表面层次。
- 同类控件统一正常、按下、选中、聚焦、错误、禁用和加载状态。
- 所有可交互控件的有效触控区域至少 48dp；视觉圆钮可以小于触控区域。
- 长文案和大字号允许布局增高或重新排列，避免固定高度裁切文字。

首期采用现有 Compose 圆角形状实现。dsh-Go 使用的连续曲率超椭圆不等同于 `RoundedCornerShape`；精确复现曲率作为后续独立优化，不作为控件统一的前置条件。

## 4. 主题与设计令牌

### 4.1 统一主题入口

新增 `ui/theme/ClawSeedTheme.kt`，输入 `dark`、`oled` 和内容，内部组合：

1. 现有 `appColorScheme()`；
2. `ClawSeedTypography`；
3. Material 3 `Shapes`；
4. 必要的自定义语义色、材质和动效设置，通过 `CompositionLocal` 向组件提供。

`MainActivity` 继续读取现有主题偏好，仅替换主题包装。避免在页面中另建浅色/深色判断和第二套颜色表。

### 4.2 令牌目标

| 类型 | 建议值/用途 |
|---|---|
| 间距 | 4、8、12、16、20、24、32dp |
| 页面边距 | 16dp；浮动输入栏沿用 12dp |
| 圆角 | 6、10、14、20、28dp，另设圆形和胶囊 |
| 普通按钮 | 最小高度 50dp，水平内边距约 24dp |
| 图标按钮 | 视觉尺寸 44–48dp，有效触控区域至少 48dp |
| 设置行 | 单行最小 52dp，双行最小 64dp；大字号自动增高 |
| 设置图标槽 | 32dp，文字间距 12dp |
| 卡片内边距 | 16dp；分组间距 24dp |
| 文字 | 界面正文约 14sp，对话正文约 16sp；标题和按钮通过语义字阶取值 |

保留已有 `ClawSeedShapes.Small/Medium/Large/Sheet` 的兼容入口，先新增语义形状并逐页迁移，避免修改旧常量立即影响所有页面。`ClawSeedColors` 中与 `AppColors` 重复的值先核对引用，再合并或移除。

UI 正文使用系统字体；代码继续使用等宽字体。新增动效令牌覆盖按压、状态淡变、展开收起和弹层，支持系统减少动画设置。首期不新增字体包、多配色选择或壁纸取色。

## 5. 公共组件设计

组件放在 `ui/components/`，保持无业务状态：页面传值和回调，组件内部只管理焦点、按压或短暂动画状态。优先包装 Material 3 控件，保留其输入、焦点和无障碍能力。

### 5.1 按钮

新增 `ClawSeedButton.kt` 和 `ClawSeedIconButton.kt`：

- 提供主按钮、描边按钮、文字按钮和图标按钮。
- 统一形状、内边距、最小高度、文字样式和禁用态。
- 加载态保持按钮宽度稳定，阻止重复提交，并提供明确的加载语义。
- 危险操作使用明确的语义参数或专用变体，避免页面直接指定颜色。
- 图标按钮接受内容描述；有提示需求时统一 Tooltip。
- 按压缩放只作用于视觉层，不缩小触控区域，不用于正在编辑的输入框。

### 5.2 表单输入框

新增 `ClawSeedTextField.kt`，基于 `OutlinedTextField`：

- 统一 14dp 圆角、表面填充、边框和文字层级。
- 普通边框使用 outline，聚焦使用 primary，错误使用 error，禁用态降低强调程度。
- 保留 label、placeholder、supportingText、前后图标、密码转换、键盘选项和 IME 回调。
- 区分只读和禁用，保留必要的复制、选择和错误提示行为。
- 不强制固定高度，支持多行、中英文及系统字体缩放。

聊天输入栏继续使用现有 `BasicTextField`，只共享令牌和外壳，不强行套用表单输入框。

### 5.3 选项与分段控件

新增 `ClawSeedChoiceChip.kt`：

- 未选中为淡中性背景，选中为清晰的中性实心或主题容器色。
- 普通筛选和主操作具有不同视觉权重。
- 单选、多选分别提供正确的选择语义；是否显示勾选标记由选择类型决定。
- 保留至少 48dp 触控区域，选项较多时使用 FlowRow 或横向滚动。

新增 `ClawSeedSegmentedPill.kt`，用于少量互斥选项：

- 等宽分段和内部选中滑块，统一内边距。
- 优先保持可读字号；放不下时由父布局将控件移到标题下方或改为纵向选项。
- 使用互斥选择组语义，并保证键盘和 TalkBack 可操作。
- 点击选择为首期必需；拖动吸附、触觉反馈和滑块动画在基本选择行为验证后实现。

### 5.4 设置行与分组

新增 `SettingsRow.kt`、`SettingsGroup.kt`：

- 固定图标槽、文字起始位置、值、箭头和 Switch 的对齐规则。
- 标题、副标题和当前值共用字阶及语义颜色。
- `SettingsSwitchRow` 由整行负责切换，内部 Switch 避免重复触发；读屏暴露为一个开关。
- 导航行显示当前值和箭头，只读信息行不呈现可点击反馈。
- 分组通过统一卡片与留白表达，避免多层 Card 嵌套。

## 6. 材质与浮层

扩展现有 `GlassSurface`，逐步提供 Chrome、Sheet、Surface、Pill 四种材质角色：

| 角色 | 使用位置 | 首期实现 |
|---|---|---|
| Chrome | 顶栏、聊天输入条、浮动圆钮 | 可读填充、细边框，按页面需要保留有限阴影 |
| Sheet | 底部弹层、抽屉 | 较高不透明度，统一圆角与遮罩 |
| Surface | 普通卡片、设置分组 | 填充与细边框，无动态模糊 |
| Pill | 小型状态与选项容器 | 轻量填充，无动态模糊 |

保留 `Elevated` 的过渡兼容入口，在所有调用完成迁移后再清理。现有 `GlassSurface` 强制使用满宽 Column，适合卡片；圆钮和胶囊需要通用内容槽。可在内部抽取通用表面绘制，同时保留原 Column 包装，避免直接破坏既有布局。

首期不实现真实背景模糊。`Modifier.blur()` 模糊自身内容，不能作为背景采样的替代；后续若实现 Android 12+ 模糊，需要独立评估背景采样、裁剪、滚动成本和 RenderEffect 管线。Android 11 以下以及性能降级状态始终保留填充方案。

弹层和对话框沿用 Material 容器及现有关闭行为，逐步包装共同的颜色、形状、标题、操作栏和键盘避让。不要在视觉迁移时改变未保存内容的关闭策略。

## 7. 开发阶段和交付物

### 阶段 A：主题基础与设置页试点

1. 建立 `ClawSeedTheme`、字体、间距、形状和基础状态令牌。
2. 实现四类按钮、表单输入框、ChoiceChip、设置行和分组。
3. 迁移 `SettingsScreen` 的实际调用；共用的 `VisionModeSelector` 同步接入。
4. 迁移时保持配置值、保存时机、加载与错误处理不变。
5. 提供组件预览和设置页浅色/深色对照截图。

完成标准：代表性设置页面的按钮、输入框、开关和选项来自公共组件，页面不再重复定义这些控件的基础样式，现有设置行为验证通过。

### 阶段 B：选择控件与材质

1. 实现 `ClawSeedSegmentedPill`，验证窄屏和大字号布局。
2. 扩展 `GlassSurface` 材质角色，维护旧调用兼容。
3. 收敛卡片、弹层标题和操作栏样式。

完成标准：选择状态清晰、语义正确；禁用/只读行为一致；材质降级不影响信息可读性。

### 阶段 C：聊天与抽屉

1. 迁移 `ChatBottomBar` 的材质、附件入口、发送与停止按钮。
2. 迁移 `EmptyChatState` 建议胶囊、`PersonaPickerSheet` 和相关弹层。
3. 迁移 `SessionDrawer` 的常用操作与选中态。
4. 保持单层输入栏、IME 避让、输入草稿、附件状态和现有 testTag。

完成标准：单行输入栏约 56dp，多行只向上扩展；聚焦不移动整个控件；键盘、发送、停止、附件和会话切换均保持原行为。

### 阶段 D：其余页面与清理

依次迁移 `ScheduledTasksScreen`、`PersonaManagerScreen`、`UserProfileScreen` 及剩余对话框、提示组件。每次迁移一个页面，删除已经被公共组件取代的局部样式。清理不再使用的令牌与兼容入口，不扩展业务流程。

## 10. 实施记录（2026-11-05）

已落地：

- `ClawSeedTheme` 统一颜色、字体和 Material 形状；新增间距、尺寸、语义形状和动效令牌，删除未引用的重复 `ClawSeedColors`。
- 新增主按钮、描边按钮、文字按钮、图标按钮、表单输入框、选项、分段选择、设置行、设置分组及底部弹层组件。加载按钮保留内容测量宽度并禁用提交；图标按压只缩放视觉内容；Compose 动画使用系统动画时长缩放。
- 单选、多选、只读标签分别提供对应语义；设置开关由整行切换；分段选择在窄屏和大字号下使用纵向布局。复杂模型和技能编辑器仍保留原有业务布局。
- `GlassContainer` 提供通用内容槽；`GlassSurface` 保留 Column 兼容入口；Chrome、Sheet、Surface、Pill 使用可读填充，保留 Elevated 兼容角色。
- 设置页、视觉模式选择、数据迁移页面、聊天与附件操作、建议胶囊、Persona 弹层、抽屉操作、定时任务、Persona 管理和用户资料已迁移对应公共组件。具有业务含义的 Persona/错误卡片颜色保留。
- 聊天仍采用 `BasicTextField`，保留 56dp 最小高度、4dp 阴影、草稿与附件回调和 testTag；停止按钮改用静态图标及共享按压反馈。
- 新增浅色、深色及 320dp/2 倍字号组件预览。新增 Compose instrumentation 测试覆盖整行开关、单选/多选、加载防重复提交及输入错误语义；补齐测试依赖。对比度测试覆盖材质透明合成、输入边界和错误状态。

验证结果与设备限制见 [控件统一验证记录](android-ui-component-unification-verification.md)。首轮未连接设备；第二轮已在 Android 16 真机保存首页与设置页前后对照、浅色/OLED 及 IME 截图，详见验证记录。instrumentation、TalkBack、完整尺寸/字号/系统版本矩阵和流式滚动性能仍未验收。第二轮经用户确认，顶部改为统一操作栏、建议项改为图标卡片，并将输入栏阴影由 4dp 调整为 2dp。


第三轮继续落地共享 `ClawSeedCard` 和 `ClawSeedNavigationRow`，调整分身、任务、资料列表的内容与操作分区，复核抽屉选中态并覆盖安装正式版。详情和明确未完成项见验证记录第三轮。

第四轮继续落地 `ClawSeedFormDialog` 和 `ClawSeedExpandableSection`：任务/资料表单统一固定标题、滚动内容及按钮区，分身编辑页统一展开分组与设置开关，增加键盘避让和可换行操作区。已覆盖安装并真机检查表单键盘滚动、内外点击关闭行为和编辑页布局；截图及待验收项见验证记录第四轮。
