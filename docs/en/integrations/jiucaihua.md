# Jiucaihua Android App Integration

[Jiucaihua](https://github.com/lzx1413/jiucaihua-android) is a personal investment
management app and a real-world provider for the ClawSeed External Tool Protocol
(CETP). When both apps are installed, ClawSeed discovers Jiucaihua's provider and
registers its tools in the active agent session.

## How It Works

```text
ClawSeed Android app
  -> discovers com.clawseed.action.TOOL_PROVIDER
  -> reads Jiucaihua tool schemas through ContentProvider
  -> registers namespaced tools such as jiucaihua__get_portfolio_analysis
  -> executes a selected tool in Jiucaihua
  -> returns the structured result to the ClawSeed agent loop
```

Jiucaihua keeps ownership of its data and business logic. ClawSeed supplies the
conversation, model selection, persona, memory, planning, and multi-tool loop.

## Available Capabilities

The integration exposes 19 namespaced tools, including:

- portfolio and individual holding analysis
- K-line data and technical indicator snapshots
- market and stock news
- market indices, market status, fund flow, and security search
- watchlist, alerts, transactions, realized returns, and portfolio performance
- what-if analysis for target prices or percentage changes

The full schema and parameter list live in the
[Jiucaihua Tool Provider documentation](https://github.com/lzx1413/jiucaihua-android/blob/main/docs/tool-provider.md).

## Setup

1. Install a recent [ClawSeed Android release](https://github.com/lzx1413/clawseed/releases/latest).
2. Build and install Jiucaihua from its
   [GitHub repository](https://github.com/lzx1413/jiucaihua-android).
3. Open Jiucaihua once so its local portfolio data and provider are ready.
4. Start a new ClawSeed session. CETP providers are rescanned when the session
   attaches, and Jiucaihua tools appear with the `jiucaihua__` prefix.

## Example Prompts

```text
Analyze my current portfolio and summarize the three largest concentration risks.

Compare my largest holding with its recent K-line indicators and relevant news.

Calculate realized returns and cash flow for the last 90 days, then explain the result.
```

These requests can trigger several Jiucaihua tools in sequence. The final answer is
generated by the active ClawSeed persona and can use its profile, memory, and speech
output settings.

## Read-Only Core and Side Effects

CETP v1 defines a read-only interoperability core. Jiucaihua's portfolio, market,
news, watchlist, transaction, and analysis tools fit that contract. Jiucaihua also
currently exposes `jiucaihua__create_alert` and `jiucaihua__delete_alert`; these
change application state and should be treated as side-effecting extensions rather
than read-only CETP v1 operations.

The provider uses an explicit external-tool allowlist and the
`com.clawseed.permission.ACCESS_TOOLS` Android permission. Because that permission
has `normal` protection level, the allowlist and provider-side authorization remain
important security boundaries.
